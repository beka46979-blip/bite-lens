## 🔄 Как это работает сейчас

### Шаг 1: Регистрация
```
Пользователь → Форма регистрации → API /register
                                    ↓
                        Сохранение в pending_registrations
                                    ↓
                        Установка tempToken cookie
                                    ↓
                        Редирект на /verify-email
```

### Шаг 2: Верификация
```
Страница /verify-email → Автоматическая отправка кода
                                    ↓
                        Пользователь вводит код
                                    ↓
                        API /verify-email/verify
                                    ↓
                        ✅ Создание пользователя в users
                        ✅ Создание сессии
                        ✅ Создание подписки
                        ✅ Удаление из pending_registrations
                        ✅ Удаление tempToken
                        ✅ Установка auth cookies
                                    ↓
                        Редирект в /profile
```

### Шаг 3: Изменение данных (опционально)
```
Кнопка "Изменить email или пароль"
                ↓
    Очистка tempToken (API /clear-temp-token)
                ↓
    Редирект на /register
                ↓
    Пользователь может зарегистрироваться заново
```

## 📝 Что можно протестировать

1. **Регистрация:**
   - Перейти на http://localhost:3000/register
   - Заполнить форму
   - Нажать "Зарегистрироваться"
   - Должен быть редирект на `/verify-email`

2. **Верификация:**
   - На странице `/verify-email` должен автоматически отправиться код
   - Ввести 6-значный код (если SMTP не настроен, код покажется на странице)
   - После успешной верификации → редирект в `/profile`

3. **Изменение данных:**
   - На странице `/verify-email` нажать "Изменить email или пароль"
   - Должен быть редирект на `/register`
   - Можно зарегистрироваться с другими данными
