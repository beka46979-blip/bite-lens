# 🐛 Отладка проблемы с кодом верификации

## Проблема
После изменения пароля и повторной регистрации, код верификации не работает - выдает "Неверный код".

## Что было исправлено

### 1. Добавлено подробное логирование

#### В `/api/auth/register`:
```
✅ Регистрация успешна: email
🔑 Создан tempToken для: email
📧 НОВЫЙ код верификации: 123456
⏰ Код действителен до: дата и время
```

#### В `/api/auth/verify-email/send-code`:
```
🔄 Генерация нового кода для: email
📧 НОВЫЙ код: 123456
⏰ Действителен до: дата и время
```

#### В `/api/auth/verify-email/verify`:
```
🔍 Проверка кода для: email
📝 Введенный код: 123456
✅ Ожидаемый код: 123456
⏰ Срок действия: дата и время
🕐 Текущее время: дата и время
```

## Как протестировать

### Шаг 1: Откройте терминал сервера
Смотрите логи в терминале, где запущен `npm run dev`

### Шаг 2: Зарегистрируйтесь
1. Откройте http://localhost:3000/register
2. Введите email и пароль
3. Нажмите "Зарегистрироваться"
4. **Смотрите в терминал** - должен появиться код:
   ```
   📧 НОВЫЙ код верификации: 123456
   ```

### Шаг 3: Проверьте код на странице
1. На странице `/verify-email` должно быть сообщение:
   - Если SMTP настроен: "Код отправлен на ваш email"
   - Если SMTP НЕ настроен: "Email не настроен. Код для демо: 123456"

### Шаг 4: Введите код
1. Введите 6-значный код из терминала или со страницы
2. Нажмите "Подтвердить"
3. **Смотрите в терминал** - должны появиться логи проверки

### Шаг 5: Если нажали "Изменить email или пароль"
1. Вернетесь на `/register` с заполненным email
2. Измените пароль
3. Нажмите "Зарегистрироваться"
4. **ВАЖНО:** В терминале появится НОВЫЙ код
5. **Используйте НОВЫЙ код**, а не старый!

## Возможные причины ошибки

### 1. Используете старый код
**Проблема:** После изменения пароля генерируется новый код, но вы вводите старый.

**Решение:** 
- Смотрите в терминал сервера
- Используйте последний код из логов
- Или нажмите "Отправить код повторно"

### 2. Код истек
**Проблема:** Код действителен 15 минут. Если прошло больше времени, код истекает.

**Решение:**
- Нажмите "Отправить код повторно"
- Используйте новый код

### 3. Несоответствие email
**Проблема:** Код привязан к email. Если вы изменили email, нужен новый код.

**Решение:**
- Убедитесь, что используете правильный email
- Проверьте логи в терминале

## Пример правильного flow

### Первая попытка:
```
1. Регистрация: test@example.com + password123!
   Терминал: 📧 НОВЫЙ код верификации: 123456
2. Ввод кода: 123456
   Терминал: ✅ Код верный! Создаем пользователя...
3. Успех!
```

### Изменение пароля:
```
1. Нажали "Изменить email или пароль"
2. Вернулись на /register
3. Изменили пароль: password123! → newPassword456!
4. Нажали "Зарегистрироваться"
   Терминал: 📧 НОВЫЙ код верификации: 789012  ← НОВЫЙ КОД!
5. Ввод НОВОГО кода: 789012  ← НЕ 123456!
   Терминал: ✅ Код верный! Создаем пользователя...
6. Успех!
```

## Что смотреть в терминале

### При регистрации:
```
✅ Регистрация успешна: test@example.com
🔑 Создан tempToken для: test@example.com
📧 НОВЫЙ код верификации: 123456  ← ЭТОТ КОД ИСПОЛЬЗОВАТЬ
⏰ Код действителен до: 31.05.2026, 12:30:00
🍪 tempToken cookie установлен
```

### При проверке кода:
```
🔍 Проверка кода для: test@example.com
📝 Введенный код: 123456
✅ Ожидаемый код: 123456  ← ДОЛЖНЫ СОВПАДАТЬ
⏰ Срок действия: 31.05.2026, 12:30:00
🕐 Текущее время: 31.05.2026, 12:15:00
✅ Код верный! Создаем пользователя...
```

### Если код неверный:
```
🔍 Проверка кода для: test@example.com
📝 Введенный код: 123456
✅ Ожидаемый код: 789012  ← НЕ СОВПАДАЮТ!
❌ Неверный код для: test@example.com
   Введено: 123456
   Ожидается: 789012
```

## Решение

1. **Всегда смотрите в терминал** - там показывается актуальный код
2. **После изменения пароля** - используйте НОВЫЙ код из терминала
3. **Если код не работает** - нажмите "Отправить код повторно"
4. **Проверьте время** - код действителен 15 минут

## Готово!

Теперь с подробным логированием вы сможете точно увидеть, какой код ожидается и какой вводится.
