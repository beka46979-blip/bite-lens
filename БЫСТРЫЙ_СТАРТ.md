# 🚀 Быстрый старт: Деплой на Timeweb за 15 минут

## Шаг 1: Подготовка (5 минут)

### 1.1 Создайте PostgreSQL базу данных
Выберите один из вариантов:
- **Timeweb Cloud Database** ⭐ (рекомендуется)
- Supabase (бесплатный tier)
- Neon (бесплатный tier)
- Railway

Сохраните строку подключения:
```
postgresql://username:password@host:5432/database_name
```

### 1.2 Создайте S3 бакет
1. Откройте [Timeweb Cloud Storage](https://timeweb.cloud/storage)
2. Создайте новый бакет
3. Получите Access Key и Secret Key

### 1.3 Сгенерируйте JWT_SECRET
```bash
node generate-jwt-secret.js
```
Скопируйте сгенерированную строку.

---

## Шаг 2: Деплой на Timeweb (5 минут)

### 2.1 Создайте приложение
1. Откройте [Timeweb App Platform](https://timeweb.cloud/app-platform)
2. Нажмите **"Создать приложение"**
3. Подключите ваш GitHub/GitLab репозиторий
4. Выберите ветку (main или master)
5. Timeweb автоматически обнаружит Dockerfile ✅

### 2.2 Добавьте переменные окружения
В разделе **"Переменные окружения"** добавьте:

```bash
# База данных
DATABASE_URL=postgresql://user:password@host:5432/database

# JWT Secret (из шага 1.3)
JWT_SECRET=ваш-сгенерированный-секрет

# URL приложения (временно, обновите после создания)
NEXT_PUBLIC_APP_URL=https://your-app.timeweb.cloud

# Google OAuth (получите на console.cloud.google.com)
GOOGLE_CLIENT_ID=your-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-secret

# Email для 2FA
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-app-password

# OpenAI (получите на platform.openai.com)
OPENAI_API_KEY=sk-proj-your-key

# S3 Storage (из шага 1.2)
S3_ENDPOINT=https://s3.twcstorage.ru
S3_BUCKET_NAME=your-bucket-name
S3_ACCESS_KEY=your-access-key
S3_SECRET_KEY=your-secret-key
S3_REGION=us-east-1

# Production
NODE_ENV=production
```

### 2.3 Запустите деплой
1. Нажмите **"Создать приложение"**
2. Дождитесь завершения (5-10 минут)
3. Получите технический домен от Timeweb

---

## Шаг 3: Настройка после деплоя (5 минут)

### 3.1 Обновите URL приложения
1. Скопируйте ваш домен от Timeweb (например: `your-app.timeweb.cloud`)
2. В переменных окружения обновите:
   ```
   NEXT_PUBLIC_APP_URL=https://your-app.timeweb.cloud
   ```
3. Сохраните изменения (приложение перезапустится автоматически)

### 3.2 Настройте Google OAuth
1. Откройте [Google Cloud Console](https://console.cloud.google.com/)
2. Перейдите в **APIs & Services → Credentials**
3. Выберите ваш OAuth 2.0 Client
4. В **Authorized redirect URIs** добавьте:
   ```
   https://your-app.timeweb.cloud/api/auth/google/callback
   ```
5. Сохраните

### 3.3 Проверьте работу
```bash
# Health check
curl https://your-app.timeweb.cloud/api/health

# Должен вернуть:
# {"status":"healthy","database":"connected",...}
```

## 🆘 Проблемы?

### Приложение не запускается
1. Проверьте логи в панели Timeweb
2. Убедитесь что все переменные окружения установлены
3. Проверьте `DATABASE_URL`

### Ошибка сборки Docker
```bash
# Используйте упрощенный Dockerfile:
mv Dockerfile Dockerfile.multi-stage
mv Dockerfile.simple Dockerfile
git commit -am "Use simple Dockerfile"
git push
```

### Google OAuth не работает
- Проверьте redirect URI в Google Console
- Убедитесь что `NEXT_PUBLIC_APP_URL` правильный
