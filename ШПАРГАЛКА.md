# 📝 Шпаргалка: Деплой на Timeweb

## 🎯 Быстрые команды

```bash
# Генерация JWT_SECRET
npm run generate:jwt

# Проверка переменных окружения
npm run check:env

# Локальное тестирование Docker
npm run docker:build
npm run docker:run

# Проверка перед деплоем
npm run deploy:check
```

## 🔑 Обязательные переменные для Timeweb

```bash
DATABASE_URL=postgresql://user:pass@host:5432/db
JWT_SECRET=your-64-char-secret
NEXT_PUBLIC_APP_URL=https://your-app.timeweb.cloud
GOOGLE_CLIENT_ID=your-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-secret
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-app-password
OPENAI_API_KEY=sk-proj-your-key
S3_ENDPOINT=https://s3.twcstorage.ru
S3_BUCKET_NAME=your-bucket
S3_ACCESS_KEY=your-key
S3_SECRET_KEY=your-secret
S3_REGION=us-east-1
NODE_ENV=production
```

## 🐳 Docker команды

```bash
# Сборка
docker build -t bite-lens .

# Запуск
docker run -p 3000:3000 --env-file .env bite-lens

# Логи
docker logs -f bite-lens-app

# Остановка
docker stop bite-lens-app

# Очистка
docker system prune -a
```

## 🔍 Проверка работы

```bash
# Health check
curl https://your-app.timeweb.cloud/api/health

# Ожидаемый ответ:
# {"status":"healthy","database":"connected",...}
```

## 🆘 Быстрые решения

### Ошибка сборки Docker
```bash
mv Dockerfile Dockerfile.multi-stage
mv Dockerfile.simple Dockerfile
git commit -am "Use simple Dockerfile"
git push
```

### Проверка переменных
```bash
node check-env.js
```

### Проверка логов в Timeweb
Панель → Ваше приложение → Логи
