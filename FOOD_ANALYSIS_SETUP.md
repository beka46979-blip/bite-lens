# 🍽️ Настройка анализа еды с помощью OpenAI GPT-4 Vision

## Описание

Система использует **OpenAI GPT-4o-mini** (GPT-4 Omni mini) для автоматического анализа фотографий еды и определения калорийности и питательной ценности.

## Возможности

- 📸 Загрузка фото еды с камеры или галереи
- 🤖 Автоматический анализ с помощью AI
- 📊 Определение калорий, белков, жиров и углеводов
- 🍕 Распознавание отдельных продуктов на фото
- 💾 Автоматическое сохранение в базу данных
- 📈 Обновление дневной статистики питания

## Настройка

### 1. Получите API ключ OpenAI

1. Зарегистрируйтесь на [OpenAI Platform](https://platform.openai.com/)
2. Перейдите в раздел [API Keys](https://platform.openai.com/api-keys)
3. Создайте новый API ключ
4. Скопируйте ключ (он начинается с `sk-proj-...`)

### 2. Добавьте ключ в .env файл

```env
OPENAI_API_KEY="sk-proj-ваш-ключ-здесь"
```

### 3. Установите зависимости

```bash
npm install openai
```

## Использование

### Для пользователей

1. Перейдите на страницу `/scan-food`
2. Сделайте фото еды или загрузите из галереи
3. Нажмите "Анализировать"
4. AI автоматически определит:
   - Название блюда
   - Общую калорийность
   - Белки, жиры, углеводы
   - Примерный вес
   - Список продуктов на фото
5. Результаты автоматически сохраняются в базу данных
6. Вы будете перенаправлены в дашборд через 2 секунды

**POST** `/api/food/analyze`

**Request Body:**

## Модель AI

Используется модель **gpt-4o-mini** (GPT-4 Omni mini):
- Быстрая обработка
- Высокая точность распознавания
- Поддержка изображений
- Оптимальная стоимость

## Логирование

Все запросы к AI логируются в таблицу `ai_logs`:
- Модель: `gpt-4o-mini`
- Количество токенов
- Статус (SUCCESS/FAILED)
- Запрос и ответ

## База данных

### Таблицы

1. **food_snaps** - сохраненные фото еды
   - image_url (base64)
   - dish_name
   - calories, proteins, fats, carbs
   - weight_gram
   - ai_verdict
   - confidence_score

2. **meals** - приемы пищи
   - meal_type (BREAKFAST, LUNCH, DINNER, SNACK)
   - user_id
   - created_at

3. **daily_nutrition_summary** - дневная статистика
   - total_calories
   - total_proteins, total_fats, total_carbs
   - snaps_count
   - kcal_target, kcal_diff

4. **ai_logs** - логи AI запросов
   - model_name
   - tokens_used
   - status
   - request_payload, response_payload

## Стоимость

GPT-4o-mini стоимость (примерно):
- Input: $0.15 / 1M tokens
- Output: $0.60 / 1M tokens

Один анализ фото обычно использует ~500-1000 токенов (~$0.001 за запрос).

## Ограничения

- Максимальный размер изображения: 10MB
- Поддерживаемые форматы: JPG, PNG, WEBP
- Изображение должно быть в формате base64 или URL

## Безопасность

- API ключ хранится в переменных окружения
- Доступ только для авторизованных пользователей
- Валидация размера и типа файла
- Логирование всех запросов

## Troubleshooting

### Ошибка "Invalid API key"
- Проверьте, что ключ правильно скопирован в `.env`
- Убедитесь, что ключ активен на OpenAI Platform

### Ошибка "Rate limit exceeded"
- Превышен лимит запросов
- Подождите или увеличьте лимит на OpenAI Platform

### Ошибка "Invalid image format"
- Убедитесь, что изображение в формате base64
- Проверьте, что изображение начинается с `data:image/`

### AI возвращает неточные данные
- Убедитесь, что фото четкое и хорошо освещено
- Попробуйте сфотографировать еду с другого угла
- Проверьте поле `confidence` - низкая уверенность (<0.5) означает, что AI не уверен
