```
┌─────────────────────────────────────────────────────────┐
│                    GitHub/GitLab                        │

                     │
                     ↓
┌─────────────────────────────────────────────────────────┐

└────────────────────┬────────────────────────────────────┘
                     │
                     ↓

│                  Nginx + SSL                            │

│  • SSL-сертификат Let's Encrypt                        │

                     │
                     ↓
                 Internet 🌍
```

## ⚠️ Важные замечания

### Безопасность
- ✅ Файл `.env` НЕ должен быть в Git
- ✅ Переменные передаются через Timeweb UI
- ✅ Используйте сильный JWT_SECRET (64+ символов)
- ✅ Регулярно обновляйте зависимости

### База данных
- ✅ Используйте внешнюю PostgreSQL
- ✅ Миграции применяются автоматически при деплое
- ✅ Делайте регулярные бэкапы

### Хранилище
- ✅ Используйте S3 для изображений
- ✅ Не храните файлы внутри Docker контейнера
- ✅ Контейнер пересоздается при каждом деплое
